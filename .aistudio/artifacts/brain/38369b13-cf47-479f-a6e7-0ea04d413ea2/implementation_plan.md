# Обновление negai v2.1.0: Планетарное меню версии, локализация (RU/EN), очистка дублей и релизная документация

Комплексное обновление видеоплеера **negai** до версии **v2.1.0**, включающее устранение дублирующихся текстовых подписей и плашек, интерактивное окно «О приложении» с минималистичной орбитальной анимацией планетарной системы при нажатии на бейдж версии, переключение языка интерфейса (Системный / Русский / English), оптимизацию стабильности и подготовку репозитория GitHub (`README.md` + семантические релизы `v2.1.0`).

### User Review & Critical Decisions

> [!IMPORTANT]
> Все ключевые решения согласованы по результатам уточняющих вопросов и заложены в архитектуру обновления:

- **Поддержка языков интерфейса**: Добавляется переключатель языка с тремя режимами — **Системный автовыбор (Auto)**, **Русский (RU)** и **English (EN)** — с мгновенным переключением всех разделов приложения, настроек и элементов видеоплеера без перезапуска процесса.
- **Устранение дублирующихся надписей и индикаторов**: Удаляются лишние повторяющиеся подписи (дублирующий бейдж версии `negai v2.0` и заголовок внутри вкладки «Настройки», статическая плашка декодера `HW+` в шапке главного экрана вне плеера, повторяющийся счётчик серии в подзаголовке шапки плеера при включённой кнопке серий, а также дублирующие секции скорости, масштаба и плейлиста внутри модального окна декодера). Все функциональные кнопки управления сохраняются на своих местах.
- **Семантическая нумерация релизов**: Версия проекта обновляется до **`v2.1.0`** (`versionCode = 3`, `versionName = "2.1.0"`), а пайплайн GitHub Actions формирует семантические релизы `v2.1.0` с подробным журналом изменений.

### 1. Overview & Core Concept

- **Что делает обновление**:
  1. **Очистка визуального шума**: Убирает дублирующиеся текстовые метки, повторные номера версий и избыточные секции в модальных окнах, оставляя интерфейс чистым и лаконичным.
  2. **Интерактивный бейдж версии с планетарной системой**: Превращает бейдж версии `v2.1.0` в верхней панели главного экрана в интерактивную кнопку, открывающую стильное модальное окно с плавной векторной анимацией минималистичной планетарной системы (центральное светило `negai` и вращающиеся по эллиптическим и круговым орбитам спутники ключевых технологий) и карточками основных возможностей плеера.
  3. **Многоязычный интерфейс (Auto / RU / EN)**: Позволяет переключать язык интерфейса на лету между системным языком, русским и английским.
  4. **Аудит стабильности и производительности**: Изолирует высокочастотные обновления состояния, защищает жизненный цикл OpenGL-поверхности и звукового процессора при переключении потоков и поворотах экрана.
  5. **Документация GitHub (`README.md`) и релизы `v2.1.0`**: Создаёт подробный `README.md` с архитектурой, возможностями и инструкцией по сборке, а также синхронизирует версию `v2.1.0` с автоматической публикацией релизов.
- **Целевая аудитория**: Пользователи локальных коллекций аниме, фильмов и сериалов (MKV/MP4, внешние дорожки `.mka`/`.ass`, стриминг через TorrServer), ценящие чистый OLED-интерфейс, плавность и поддержку русского и английского языков.
- **Ключевая ценность**: Единообразный минималистичный интерфейс без визуального дублирования, наглядная презентация возможностей плеера прямо из шапки приложения и полноценная готовность проекта к публикации на GitHub.

### 2. User Experience & Visual Design

- **Ключевые пользовательские сценарии**:
  1. **Интерактивное окно версии («Планетарная система negai v2.1.0»)**:
     - Нажатие на бейдж `v2.1.0` в верхней панели открывает окно `VersionPlanetaryModalSheet`.
     - В верхней части окна на тёмном космическом градиенте отрисовывается минималистичная планетарная система на `Canvas`: центральное ядро `negai 2.1.0` с мягким акцентным свечением и 4 орбитальных кольца с плавно движущимися спутниками (`Anime4K GLSL`, `MEMC 120Hz`, `Audio DSP ±5s`, `TorrServer`), а также тонкие звездные точки на фоне.
     - Ниже располагается структурированный список ключевых возможностей плеера (апскейлинг Anime4K, интерполяция кадров MEMC + LTPO, синхронизация и усиление звука, встроенные главы MKV/MP4, интеграция с TorrServer) и краткий список нововведений релиза `v2.1.0`.
  2. **Чистый интерфейс без дублирующих надписей**:
     - В шапке главного экрана остаётся только логотип `negai`, кликабельный бейдж `v2.1.0` и активные индикаторы только если пользователь явно включил соответствующие видеофильтры.
     - Во вкладке «Настройки» убирается дублирующая шапка `Категории настроек / negai v2.0`, так как название раздела и версия уже отображаются в панели приложения.
     - В окне «Декодер и видео» в плеере остаются только телеметрия видеопотока и выбор режима декодера (`HW+` / `HW` / `SW`), без дублирования скорости, масштаба и списка серий.
  3. **Переключение языка интерфейса**:
     - В разделе «Настройки → Внешний вид» (а также в окне быстрого выбора темы в верхней панели) доступен переключатель языка: **Системный (Auto)**, **Русский**, **English**.
     - При выборе языка все вкладки, подписи настроек, модальные окна и HUD плеера мгновенно обновляются на выбранный язык.

- **Визуальный стиль и тема**:
  - *Эстетика*: Премиальный минимализм с глубокими OLED-поверхностями, полупрозрачным матовым стеклом и тонкими геометрическими линиями орбит в окне версии.
  - *Анимация и отклик*: Бесконечная плавная анимация вращения орбит (`rememberInfiniteTransition` с линейной интерполяцией углов $\theta_1 \dots \theta_4$) выполняется исключительно внутри фазы отрисовки `Canvas`, не вызывая рекомпозиции текстовых карточек.

### 3. Key Product Decisions & Trade-Offs

- **Решение 1: Локализация через реактивный `AppLanguage` + `CompositionLocal` и ресурсы `values` / `values-en` / `values-ru`**
  - *Выбранный подход*: Хранение выбранного языка (`SYSTEM`, `RU`, `EN`) в `PlayerSettings` (DataStore) с предоставлением локализованного контекста и словаря строк через `CompositionLocalProvider` в корневом компоненте `Kino4KAppRoot`.
  - *Почему*: Позволяет мгновенно переключать язык всех экранов и диалогов в реальном времени без пересоздания `Activity` и прерывания воспроизведения видео.
- **Решение 2: Рендеринг планетарной анимации исключительно в фазе `DrawScope`**
  - *Выбранный подход*: Чтение анимированного фазового угла внутри `Canvas { ... }` с тригонометрическим расчётом координат спутников на орбитах.
  - *Почему*: Гарантирует стабильные 60/120 к/с при открытом модальном окне версии при нулевой нагрузке на дерево компоновки Compose.
- **Решение 3: Семантическая версия `v2.1.0` и динамическое определение версии в GitHub Actions**
  - *Выбранный подход*: Фиксация `versionName = "2.1.0"` и `versionCode = 3` в конфигурации сборки; workflow GitHub Actions автоматически считывает `versionName` из конфигурации проекта и формирует тег `v2.1.0` (или `v2.1.0-build.N` при повторных коммитах той же версии) с полным описанием изменений.
  - *Почему*: Исключает рассинхронизацию между номером версии внутри приложения, бейджем в шапке и названием релиза на GitHub.

### 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **Архитектура и схема взаимодействия компонентов**:

```
┌───────────────────────────────────────────────────────────────────────────┐
│                         MainActivity / Kino4KAppRoot                      │
│  ┌─────────────────────────────────────────────────────────────────────┐  │
│  │       Localization Provider (AppLanguage: SYSTEM | RU | EN)         │  │
│  └───────────────┬───────────────────────────────────┬─────────────────┘  │
│                  ▼                                   ▼                    │
│  ┌───────────────────────────────┐   ┌─────────────────────────────────┐  │
│  │      Main Library Header      │   │       Cleaned UI Surfaces       │  │
│  │  • Brand "negai"              │   │  • Settings Hub (no dup badge)  │  │
│  │  • Interactive [v2.1.0] Badge │   │  • Decoder Sheet (codec only)   │  │
│  └───────────────┬───────────────┘   │  • Player Top Bar (no dup text) │  │
│                  │ tap               └─────────────────────────────────┘  │
│                  ▼                                                        │
│  ┌─────────────────────────────────────────────────────────────────────┐  │
│  │                 VersionPlanetaryModalSheet (v2.1.0)                 │  │
│  │  • Minimalist Planetary System Canvas (4 orbits + glowing core)     │  │
│  │  • Core Capabilities Showcase (Anime4K, MEMC, Audio Sync, TorrSrv)  │  │
│  │  • Release v2.1.0 Highlights Badge & Changelog                      │  │
│  └─────────────────────────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────────────────────────┘
```

- **Модель данных и состояние**:
  - `AppLanguage` (`SYSTEM`, `RU`, `EN`): сохраняется в `PlayerPreferencesRepository` (`app_language`) и входит в `PlayerSettings`.
  - `AppVersionInfo`: единый источник правды о текущей версии (`2.1.0`, код сборки `3`, дата и список ключевых функций и изменений релиза), используемый в верхней панели и в планетарном окне «О версии».
- **Интерактивное поведение и аудит стабильности**:
  - Нажатие на `app_version_badge` открывает `VersionPlanetaryModalSheet` с возможностью переключения выбранной планеты/функции нажатием на карточку или орбиту.
  - В `PlayerEngine`, `AudioDelayProcessor` и `Anime4KVideoSurface` проверяется потокобезопасность буферов, корректное освобождение ресурсов при закрытии плеера и отсутствие лишних рекомпозиций при обновлении таймлайна.
